# Sugar Archive

基于 Rust 和 Slint 的轻量级 ZIP 压缩包管理工具，提供亮色与暗色界面。

## 运行

安装 Rust 工具链及当前平台所需的 Slint 图形依赖，然后执行：

```sh
cargo run --release
```

## 功能

- 创建、打开和查看 ZIP 压缩包。
- 通过侧边栏目录树浏览压缩包，向当前目录添加多个文件（同名文件会被拒绝）。
- 将整个压缩包解压到指定目录；为避免覆盖，已存在的目标文件会导致操作停止。
- 在侧栏切换亮色和暗色主题。

目前支持 ZIP 格式和常见的 Deflate/Stored 压缩方式，暂不支持加密压缩包、解压符号链接、添加文件夹或删除条目。打开、添加和解压操作在后台执行，文件列表按需渲染。主题设置不会跨次运行保存。
